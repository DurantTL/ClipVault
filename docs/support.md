## Diagnostics report (recommended)

In the app, open **Help → Save Diagnostics Report…**. This writes a **local** plain-text report with app version, system profile, settings, and recent project paths. Nothing is uploaded automatically — attach the file only if you choose to share it with support.

## System requirements

- Apple Silicon Mac (`arm64`)
- Recommended: M2 or newer; M2 Pro / M3 Pro / M4 Pro or better for large 4K/10-bit workflows
- 16 GB RAM minimum recommended; 32 GB+ for large event projects
- Fast SSD recommended for destinations
- macOS 15+ recommended for best performance (deployment target may be lower)

## What SlateBox helps with

- Safe copy from camera cards / folders to project destinations
- Verification, local preview, keyboard culling, and folder handoff for editors
- Local offline analysis for organizational hints (focus, exposure, faces as rectangles, stability)

## What SlateBox does not do

- Cloud sync or cloud AI review
- Editing timelines / NLE replacement
- Formatting or erasing camera cards
- Deleting or modifying original source media
- Writing production metadata into MP4/MOV files by default

## Privacy

SlateBox is local-first. See the [Privacy Policy](privacy.md) for details on offline processing, face-data limits, and what stays on your Mac.
